# Aevon Nexus

Build a premium, world-class corporate landing page for Aevon Industries. The website should feel like a blend of Apple, Google, Stripe, Microsoft, Linear, and Framer—minimal, futuristic, elegant, interactive, and highly professional. Every section should have smooth animations, premium typography, subtle gradients, glassmorphism effects, rounded corners, and responsive layouts. Use Aevon's brand colors (deep purple, royal blue, white, with black for dark mode). Include both Light and Dark Mode.

This is not a product landing page. This is the official corporate website of Aevon Industries, showcasing the company, its mission, and its entire ecosystem of products and services.

CMS REQUIREMENTS

All product cards must be powered by a CMS/database.

Each product should support the following fields:

• Product Name

• Logo

• Category

• Description

• Platform

• Status (Available, Beta, Coming Soon, In Development)

• Website URL

• Product Images

• Release Date

• Featured Toggle

• Tags

Adding a new product to the CMS should automatically create a new product card in the ecosystem section without editing the page.
